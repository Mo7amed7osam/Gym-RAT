# Product Manager — transformation
## Problem
Owner wants a premium, offline, rotation-based tracker with a familiar set-logging grid, usable by a few testers, with no accounts.

## Fixed constraints
PDF reference only · one active plan · rotation · local only · no cool-down · kg/cm only · Sets UI preserved · static media + YouTube · no paid media · all features before TestFlight.

## Scope (four tabs)
Today (next workout, resume, recommendations) · Plan (active plan, rotation, calendar, templates, editor) · Progress (history, PRs, analytics, body, goals, comparisons) · Library (catalog, illustrations, video, custom exercises).

## Success criteria
Release checklist in spec §9. Key: kill-test 10/10; rotation correct; every built-in exercise illustrated (exact) + instructions; Arabic RTL; Live Activities; Health; offline.

## Open owner decisions
D3 owner-vs-tester (default: approved program as selectable template; Starter default) · D4 program questionnaire → shortlist → approval; illustration mapping · D5 Apple credentials · D6 existing data · D8 Arabic digits · D10 drop web · D11 video list approval.

## Out of scope
Pounds/inches, plate inventory, recovery questionnaires, Apple Watch (future), public App Store, multi-plan versioning, cloud.
